# 구글 드라이브 Picker 연결하기

예약관리의 "결과물 전송" 확인모달 안에서 구글 드라이브를 직접 훑어보고
파일/폴더를 고를 수 있게 하는 기능이다. 시트·캘린더 연동(서비스 계정)과는
완전히 다른 방식 — 이건 성윤님이 직접 구글 계정으로 로그인해서 **본인의
드라이브**를 보는 것이라 OAuth 동의가 필요하다. 아래 값 두 개를 구해서
Vercel 환경변수에 넣으면 된다.

## 1. 구글 클라우드 프로젝트 준비

1. [console.cloud.google.com](https://console.cloud.google.com) 접속
2. 상단의 프로젝트 선택기에서 새 프로젝트를 만들거나(예: "푸르른 스튜디오"),
   기존에 시트/캘린더 연동용으로 만들어둔 프로젝트가 있으면 그걸 그대로 써도
   된다 — 서비스 계정과 같은 프로젝트 안에 있어도 전혀 상관없다.

## 2. API 켜기

**API 및 서비스 → 라이브러리**에서 아래 두 개를 각각 검색해서 **사용
설정**한다.

- **Google Picker API**
- **Google Drive API**

## 3. OAuth 동의 화면 설정 (처음 한 번만)

구글이 이 화면을 "Google 인증 플랫폼"이라는 마법사 방식으로 새로
바꿨다. **API 및 서비스**에서 검색창에 "Google 인증 플랫폼"(또는
OAuth)을 검색해 들어간다.

1. 개요 화면에서 **시작하기** 클릭
2. **앱 정보** — 앱 이름(예: "푸르른 스튜디오 관리자"), 사용자 지원
   이메일(본인 구글 계정) 입력 → 다음
3. **대상** — **외부(External)** 선택 → 다음 (사업자 등록된 조직
   계정/Workspace가 아니면 이것만 고를 수 있다)
4. **연락처 정보** — 본인 이메일 입력 → 다음
5. **마침** — "Google API 서비스 사용자 데이터 정책"에 동의 체크 →
   계속 → 만들기

다 만들어지면 왼쪽 메뉴 **대상** 탭에서 "테스트 사용자"에 본인 구글
계정 이메일을 추가해 둔다 — 게시 상태가 "테스트 중"이어도 여기
등록된 계정으로는 로그인해서 쓸 수 있다.

범위(Scopes)는 나중에 코드가 요청하는 `drive.readonly`만 쓰므로 여기서
따로 추가하지 않아도 된다.

## 4. OAuth 클라이언트 ID 만들기

왼쪽 메뉴 **클라이언트** 탭 → **+ 클라이언트 만들기**

- 애플리케이션 유형: **웹 애플리케이션**
- **승인된 자바스크립트 원본**에 실제 사이트 주소를 추가한다. 예:
  - `https://<Vercel 프로덕션 도메인>`
  - 커스텀 도메인을 쓰면 그 주소도 같이 추가
  - 로컬에서 테스트하려면 `http://localhost:3000`도 추가
- **리디렉션 URI는 비워둬도 된다** — 이 기능은 팝업 안에서 토큰만 받아오는
  방식(Google Identity Services)이라 별도 콜백 주소가 필요 없다.
- 만들고 나면 뜨는 **클라이언트 ID**를 복사해 둔다(비밀 클라이언트
  보안 비밀번호는 필요 없다).

## 5. API 키 만들기

**API 및 서비스 → 사용자 인증 정보 → + 사용자 인증 정보 만들기 → API 키**

- 키가 생성되면 **키 제한사항**을 눌러:
  - API 제한사항: **키 제한** → **Google Picker API**만 체크
  - (선택) 애플리케이션 제한사항 → HTTP 리퍼러 → 위에서 등록한 사이트
    주소를 추가해두면 더 안전하다.

## 6. Vercel에 값 넣기

Vercel 프로젝트 → **Settings → Environment Variables**에 아래 두 개를
추가하고 다시 배포한다.

| 이름 | 값 |
|---|---|
| `NEXT_PUBLIC_GOOGLE_PICKER_CLIENT_ID` | 4번에서 만든 OAuth 클라이언트 ID |
| `NEXT_PUBLIC_GOOGLE_PICKER_API_KEY` | 5번에서 만든 API 키 |

둘 다 브라우저 JS에서 그대로 쓰이는 값이라 `NEXT_PUBLIC_` 접두사가
붙는다 — 비밀 키가 아니라 공개돼도 되는 값이다(보안은 위 3~5번의
도메인/스코프 제한으로 건다).

## 확인하는 법

배포 후 예약관리에서 아무 예약이나 열어 **결과물 전송** 버튼 →
**구글 드라이브에서 선택**을 누르면 구글 로그인 창이 뜨고, 로그인하면
드라이브 파일/폴더 선택창이 그 안에서 바로 열린다. 값을 안 넣었으면
버튼을 눌러도 "구글 드라이브 연동이 아직 설정되지 않았습니다"라는
안내만 뜨고, 그 외 사이트 기능에는 영향이 없다.
